# 界面设计

梅花面向用日常语言处理文件和电脑任务的用户。任务输入居中，工作文件夹、模型、智能体与状态可以直接找到；写入与外部操作的确认应显示内容和理由。

## 视觉规则

主画布雪白，侧栏浅灰绿，重点操作使用梅红。梅枝和雪点作为局部装饰；像素角色表达工作状态，空闲时保持安静。

| CSS 颜色 | 用途 |
| --- | --- |
| `#f7f9f8` | 画布 |
| `#eef3f2` | 侧栏 |
| `#ffffff` | 表单与对话表面 |
| `#25343a` | 主要文字 |
| `#5d6f74` | 次级文字 |
| `#dce7e5` | 分隔线 |
| `#a7375a` | 主操作与运行状态 |
| `#f9e9ee` | 选择与提示背景 |

变量集中在 `src/style.css`，深色主题通过变量切换。采用系统字体，按钮、表单和弹窗沿用同一间距和焦点规则。

## 布局与交互

侧栏展示目录、会话和管理入口。模型选择放在消息输入框右下角，靠近发送按钮；工作文件夹、智能体和工作方式放在左侧。对话宽度上限 800px，文件/Git 预览在右侧，窄窗口改用可关闭面板。

工具结果默认折叠，代码与表格支持复制或横向滚动。附件显示名称和移除入口。需求检查、计划确认和操作确认分别展示当前选择的实际影响。

任务执行和需求检查时静音循环雪梅视频，叠加模糊与浅色/深色蒙版，并给文字保留底色。系统减少动态效果时不播放视频，同时关闭像素动作。键盘焦点和控件名称需要可见、可读；对比度目标为 WCAG AA，尚未做完整无障碍认证。

## 素材与参考

图标由 `scripts/make-meihua-icon.py` 生成；雪梅枝是 AI 生成素材，运行视频由项目发起者提供。资产位于 `assets/meihua/`，打包时由前端构建输出到 `dist/`。

导航与对话布局参考 [shadcn/ui sidebar-07](https://ui.shadcn.com/view/new-york-v4/sidebar-07) 和 [assistant-ui Thread](https://www.assistant-ui.com/elements/thread)。组件和样式在本仓库实现，未复制参考页面源码。
