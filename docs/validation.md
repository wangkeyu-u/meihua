## 审计中修复的问题

将 `source-map-js` 从 1.2.1 更新到修复版本 1.2.2，处理 [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)。其他主要运行时版本保持锁定。

干净安装后的首次并行启动曾触发 Electron 延迟下载重复解压，导致两组桌面检查失败。新增安装阶段的串行准备后，从锁文件重新安装并重跑，两组均通过。

打包改为只包含运行时、前端构建、生产依赖、应用清单和第三方说明。排除了开发配置、本机评估结果和历史审阅记录；新增实际应用包检查脚本。打包器会移除应用清单的开发脚本与元数据，检查按运行所需字段比较。

README 和文档按当前源码重写，去掉过时功能说明、重复进度记录和本机安装路径，补充第三方许可、素材来源及 AI 辅助开发说明。
