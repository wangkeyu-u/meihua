# 使用与配置

## 工作文件夹与模型

首页可以创建 `梅花工作台`，也可以选择现有文件夹。文件夹限定文件工具的操作范围；执行中需要先暂停任务才能切换目录。文件/Git 面板只做预览，不提供暂存或 Git 回滚。

输入框右下角可以切换已连接的提供方与模型，或打开模型设置。设置按提供方保存模型、接口地址和密钥。

需求检查模型默认沿用执行提供方，也可连接另一家服务。分工子代理在“任务、用量与工具设置”中独立选择提供方、模型和地址，默认采用该提供方的检查模型预设；它不依赖需求检查模型的选择。规划使用需求检查模型，过程监督和最终核对使用执行模型。

OpenAI 兼容接口必须填写地址，例如本地 Ollama 的 `http://127.0.0.1:11434/v1`。服务需支持对应协议和工具调用。预设列表是代码中的配置，并不实时查询账号可用模型或价格；可以填写自定义模型 ID。

模型能力配置绑定提供方、模型 ID 和 API 地址。官方接口的已知模型采用 SDK 元数据，自定义接口采用保守默认值；可手动填写上下文、输出上限及能力。请求还受任务预算限制。模型改变后，旧接口的能力设置不会套用到新接口。

应用新增 API Key 和 MCP/OAuth 认证须使用系统密钥存储加密；系统不可用时拒绝保存。旧编码密钥兼容读取，重新保存后才会替换。`ZHUGE_API_KEY` 可为当前执行提供方提供环境变量密钥。应用不会把已保存的密钥回填到页面。

## 工作方式与确认

直接执行会先进行一次不带工具的需求检查。检查卡片提供修改需求、采用建议或按原需求执行的选择。检查失败时不会自动进入执行。选择“先帮我理清想法”只做需求检查。

计划和问答提供读取类工具，不开放写入、命令和外部操作。计划完成后可修改方案，再点击按计划执行。分工模式先生成结构化计划，用户确认后启动节点；修订后的计划也需确认。

运行时可发送最多 10 条补充指令。分工任务可将指令定向给步骤；主进程核对任务身份后在下一步读取。

写文件、运行命令、连接和调用 MCP、浏览器动作及本机外部操作由主进程显示内容并确认。文件或目录在确认期间改变时，旧操作会被拒绝。多个确认按顺序显示。模型参数或资料中的“已批准”不能代替界面确认。

## MCP

从侧栏“扩展工具”进入：

1. 点击查找工具，按服务名或用途检索官方 MCP Registry。
2. 选择候选，填写其版本元数据要求的密钥、路径等字段。
3. 添加服务，再点击检查连接并查看工具。

检索不发送聊天内容或模型密钥，也不会自动安装、保存或连接服务。目录记录是配置线索，不能保证外部服务兼容。生成的本机服务使用固定版本 npm/PyPI 包，需要 `npx` 或 `uvx`；首次连接会下载所选包。

手动添加支持 stdio 命令、逐行参数、环境变量，或 Streamable HTTP 地址和请求头。远程地址使用 HTTPS，回环地址允许 HTTP。保存的服务可停用或删除；任务中首次连接及工具调用仍需确认。

支持 Tools、Resources、Prompts、OAuth 登录和 form elicitation。模型可直接使用适合上下文窗口的已发现工具 schema；较大的 schema 通过通用调用入口使用。服务在调用前按最新 schema 校验参数。暂不支持 URL elicitation、旧式 HTTP+SSE 和服务器代调用模型。

项目也可在 `.zhuge/mcp.json` 中配置服务：

```json
{
  "servers": {
    "local-tools": {
      "command": "node",
      "args": ["/absolute/path/to/mcp-server.js"],
      "env": {}
    }
  }
}
```

项目 JSON 由用户维护，应用不会自动加密其中的认证信息。应用管理的服务保存在本机 `mcp-services.json`；项目服务与应用服务不能使用同一标识。

## 智能体与 Skills

“我的智能体”可以设置名称、职责、只读/完整工具模式和最多 8 个 Skill。

工作目录支持 `.agents/skills/<名称>/SKILL.md` 与 `.zhuge/skills/<名称>/SKILL.md`。也可导入含一个 `SKILL.md` 的 ZIP，并保留参考文件和脚本。导入到 `.zhuge/skills/`，同名时改用新名称，保存智能体后生效。

缺失的已选 Skill 会阻止启动。Skill 脚本沿用命令确认和沙箱规则，不能凭文本指令增加权限。项目根目录的 `AGENTS.md` 会作为项目规则读取。

## 记忆

侧栏“记忆”管理偏好与事实，可选择通用或当前工作文件夹，编辑、停用、删除和查看来源。最多 200 条，每条最多 1000 字符；检索采用本地词语匹配。

“使用记忆”和“自动整理记忆”可分别关闭。自动整理使用用户原始需求中的逐字证据，最多 3 段，不从附件、工具结果或助手回复提取偏好。事实有相关性、范围、有效期和冲突检查。

验证通过且有来源的任务可形成经验候选。候选默认停用，由用户决定是否启用；使用前再次核对来源哈希。删除记忆不会删除已包含它的会话历史。

## 权限、预算与隔离

设置可分别控制只读模式、网页读取、MCP、本机工具、命令超时和沙箱。任务开始时保存策略；恢复时权限不能超过原任务的上限。

分工最多同时运行 2 个父任务、全局 8 个节点，等待任务上限 16。每个计划最多 24 个节点；单任务并发数可设 1 至 8，默认 3。所有阶段、自动记忆与压缩调用共用本任务账本。

可以设置调用次数、Token 和 USD 费用上限，以及各模型每百万 Token 单价。供应商未返回用量时显示估算，未登记单价时显示费用未知；费用上限开启且模型价格未知时阻止请求。请求超时默认为 180 秒，可设 30 至 900 秒。已发出但结果不明的请求保守计入预算，这个记录不是供应商账单。

macOS Seatbelt 默认限制命令及本地 MCP 的目录读写，保护项目规则和配置，禁止进程联网。显式开启进程网络后不做按域名过滤；关闭沙箱后以当前账户权限运行。沙箱后端不可用时拒绝隔离启动。含 `[ ] * ?` 的工作目录暂不支持沙箱执行。

隔离浏览器须登记来源，API 须登记地址和方法。浏览器使用独立会话，不读取用户 Chrome 的登录状态。

## 验证与备份

“设置 → 权限与工具 → 任务、用量与工具设置”可选择自动检测、自定义命令或仅核对文件。

自动检测读取根 `package.json` 的 test/build/lint/typecheck 脚本。其他项目可以填写最多 8 个检查：可执行程序、JSON 参数数组、子目录、超时、预期输出和产物。程序与参数按 argv 执行，不拼接 Shell 字符串。命令执行前仍需确认；确认期间脚本或目录变化则拒绝执行。

例：程序 `python3`、参数 `["-m", "pytest"]`、子目录 `backend`。所需环境须已安装。验证配置在任务开始时固定，恢复和修复沿用该配置。

受管理的文件工具在修改前后保存 checkpoint，可在时间线查看 diff、撤销或恢复任务首次修改前状态。单份备份最多 15 MiB，单任务保守计数最多 100 MiB。命令、MCP 和邮件等副作用没有同等备份或通用撤销。

备份默认永久保留。可选 7/30/90 天，先预览再手动清理；暂停任务、未确认修改和共用内容受到保护。清理后对应任务无法再撤销，工作文件、聊天历史和迁移原始副本保留。

## 会话与附件

支持会话搜索、重命名、置顶、归档/恢复、独立复制及 Markdown 导出。复制会话保留文本，解除原任务和 checkpoint 的操作关联。

附件最多 8 个，单文件 15 MB；只提取前 30000 字符，合计 120000 字符，不提供图片理解。已提交附件保存为需求快照，未提交附件不跨重启保存。

`⌘,` 打开设置，`⌘K` 搜索任务，`⌘N` 新建任务。通知默认关闭；启用后仅在窗口不在前台且任务未取消时请求通知，展示取决于系统设置。
